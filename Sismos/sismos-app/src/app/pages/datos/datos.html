🔍¿Cómo ver los datos manualmente?

El localStorage es una pequeña base de datos que vive dentro de tu navegador. Puedes inspeccionarla en cualquier momento:

  1. Abre la página y presiona F12 (o clic derecho → "Inspeccionar") para abrir las herramientas del desarrollador.
  2. Ve a la pestaña Application (en español: "Aplicación"). Si no la ves, haz clic en el símbolo ≫ para mostrar más pestañas.
  3. En el menú lateral izquierdo, busca Storage → Local Storage (Almacenamiento → Almacenamiento local) y haz clic en http://localhost:4200.
  4. Ahí aparece la tabla con todas las claves y valores: haz clic en la fila usuarios para ver el usuario y la contraseña guardados.

Otra forma: la consola

En la pestaña Console (consola) de las mismas herramientas, puedes escribir estos comandos y presionar Enter: 

// Ver los usuarios registrados en JSON
JSON.parse(localStorage.getItem('usuarios'))

// Ver la clave de la versión anterior (HTML puro)
localStorage.getItem('userData')

// Ver si hay sesión iniciada
localStorage.getItem('isLoggedIn')

// Borrar todo
localStorage.clear()
